OSR20 实验总结: 纯特征空间OSR深度优化
============================================

════════════════════════════════════════════════════════════════════
〇、Baseline记录 (历史最优)
════════════════════════════════════════════════════════════════════

  ── osr18a (历史最优模型, FewShotFlowACModel) ──
    训练配置: FewShotFlowACModel (方案A+C, density模式)
    Flow架构: ConditionalINN(input=32, condition=0, 3 coupling layers, hidden=[32,32])
    闭集ACC: 68.89%
    最优OSR: anti_prototype 17.62%
    其他: feature_mahalanobis ~13%, geo_fusion ~14%, ood_head 10.48%
    结论: Flow仅用于分类增强, 不用于OSR

  ── osr18b/c (Flow OSR loss调参) ──
    osr18b: 强反归一化力 3.2:1 → ACC 57.60%, anti_proto 17.20%
    osr18c: 温和反归一化力 0.5:1 → ACC 64.44%, anti_proto 17.16%
    统一结论: Flow OSR loss调整对flow OSR无效, 反而伤害分类

  ── osr19a (Flow z空间教师/辅助, 全部失败) ──
    闭集ACC: 65.82%
    最优OSR: anti_prototype 17.69%
    根因: Flow z空间与特征空间同构, Flow密度与特征统计量冗余
    关键教训: Flow对OSR贡献为零, 改进应从特征空间方向寻找


════════════════════════════════════════════════════════════════════
一、osr20a 实验结果 (已完成)
════════════════════════════════════════════════════════════════════

  ── 训练配置 ──
    模型: EpisodicFlowClassifier (无Flow, 纯prototypical distance)
    从osr19a checkpoint加载失败 (架构不同) → 从头训练
    闭集Val ACC: 70.07% (osr19a: 65.82%, osr18a: 68.89%)

    Few-shot分类:
      Base:  5w1s=61.49%, 5w5s=72.75%, 5w10s=73.40%
      Novel: 4w1s=41.70%, 4w5s=45.80%, 4w10s=46.80%

  ── osr20a 关键发现 ──
    ✅ Per-class自适应阈值: anti_proto 18.92%→21.21% (+2.29%)
    ✅ OOD head扩展(5→11维): ood_head 9.01%→ood_head_ext 16.33% (+7.32%)
    ❌ 原型正则化: 无效 (K_shot=50时原型已稳定)
    ❌ 方差归一化/余弦距离: 均不如L2
    ❌ 10-shot: 反而下降 (原型质量降低)

    osr20a最优: anti_prototype_per_class_rectified TPR=21.24%

二、osr20b 实验结果 (已完成 — 达标)
════════════════════════════════════════════════════════════════════

  使用osr20a同一模型 (Val ACC 70.07%)

  ── OSR方法完整对比 (TNR≈95%, 10 rounds) ──
    ┌──────────────────────────────────────┬──────────┬──────────┬──────────┐
    │ 方法                                 │ TNR(%)   │ TPR(%)   │ OSR(%)   │
    ├──────────────────────────────────────┼──────────┼──────────┼──────────┤
    │ feature_mahalanobis                  │ 95.00    │ 12.54    │ 53.77    │
    │ anti_prototype                       │ 95.00    │ 18.92    │ 56.96    │
    │ geo_fusion                           │ 95.00    │ 14.06    │ 54.53    │
    │ ood_head                             │ 95.00    │  9.01    │ 52.00    │
    │ ood_head_extended                    │ 95.00    │ 16.33    │ 55.67    │
    │ anti_prototype_per_class             │ 94.76    │ 21.21    │ 57.99    │
    │ ood_head_extended_per_class          │ 95.68    │ 12.27    │ 53.97    │
    │ ★ ensemble_anti_oodext               │ 95.00    │ 22.91    │ 58.95    │
    │   ensemble_anti_oodext_per_class     │ 95.07    │ 20.68    │ 57.88    │
    └──────────────────────────────────────┴──────────┴──────────┴──────────┘
    ★ = 最优方法 (历史最佳)

  ── 各方向结果分析 ──

    ✅ 方向1: Ensemble anti_proto + ood_head_extended — 成功, 突破22%!
       anti_prototype: 18.92% → ensemble_anti_oodext: 22.91% (+3.99%)
       anti_prototype_per_class: 21.21% → ensemble_anti_oodext: 22.91% (+1.70%)
       融合权重: alpha=0.60 (60% anti_proto + 40% ood_head_extended)
       TNR完美保持95.00% (无需per-class即可保持)
       Youden J: 0.190 (calib 0.154 → test 0.190, 泛化良好)
       结论: anti_prototype和ood_head_extended提供真正互补的OSR信号
             anti_proto捕获几何结构, ood_head_ext捕获统计特征, 融合有效

    ❌ 方向2: ood_head_extended per-class — 失败
       ood_head_extended: 16.33% → per_class: 12.27% (-4.06%)
       TNR反而升高到95.68% → per-class阈值过于保守
       原因: ood_head_extended输出是概率值, 分布与anti_proto不同
             per-class阈值按最近类分组, 但概率分布不适合这种分治策略
       结论: per-class阈值只适用于距离型方法 (anti_proto), 不适用概率型方法

    ❌ 方向3: ensemble + per-class — 反而下降
       ensemble: 22.91% → ensemble_per_class: 20.68% (-2.23%)
       原因: ensemble的归一化已隐式处理了类间差异, per-class额外分治引入噪声
       结论: 集成与per-class阈值不兼容, 集成方法应使用全局阈值

  ── osr20b 关键发现 ──
    1. anti_prototype和ood_head_extended的信号确实互补
       → anti_proto: 基于几何距离的判别 (原型反射)
       → ood_head_ext: 基于统计特征的判别 (11维特征, logistic regression)
       → 融合后互补, 而非冗余
    2. 融合权重alpha=0.60, 非极端值, 说明两个信号都有贡献
    3. 全局阈值在集成方法上优于per-class阈值
