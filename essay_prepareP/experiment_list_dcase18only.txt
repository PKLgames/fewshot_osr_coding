================================================================================
DCASE18 实验执行指令 (仅 DCASE18, 4-fold)
对照 experiment_list.txt 的 EP1-EP4 / FP1-FP4
================================================================================

前置: DCASE18 数据集 4-fold 结构
────────────────────────────────────────────────────────────────────────────────
  每 fold 需独立训练+评估, 最终报告 4-fold 均值±标准差。
  fold=all 时脚本自动循环 fold 1→2→3→4 并汇总。

  通用参数:
    --dataset DCASE18   选择 DCASE18 数据集
    --fold 1            单 fold 运行 (默认)
    --fold all          4-fold 全跑, 自动汇总 mean±std

  类别: 5 base (0-4) + 4 novel (5-8)
    base: absence, cooking, social_activity, watching_tv, working
    novel: dishwashing, eating, other, vacuum_cleaner


================================================================================
一、FOAC-AIFP (ResNet18 backbone) — 输出至 experiment/foac_exp/
================================================================================

  初始化:
  ───────────────────────────────────────────────────────────
    mkdir -p experiment/foac_exp/{ablation,wayshot,openness,complexity,cross_domain,statistical,tsne}


  FP0 ── 预训练 Backbone (每个 fold 独立, 改 yml 后运行 main.py)
  ───────────────────────────────────────────────────────────
    # FOAC-AIFP 三阶段:
    #   预训练: pretrain: true   test: false  → python main.py
    #   训练:   pretrain: false  test: false  → python main.py
    #   评估:   pretrain: false  test: true   → python main.py
    # main.py 无单独 --fold 参数, fold 从 yml 读取

    cd /coding/FOAC-AIFP
    for fold in 1 2 3 4; do
      cp dcase18_aligned.yml dcase18_aligned_fold${fold}.yml
      sed -i "s/pretrain: false/pretrain: true/" dcase18_aligned_fold${fold}.yml
      sed -i "s/test: true/test: false/" dcase18_aligned_fold${fold}.yml
      sed -i "s/fold: .*/fold: ${fold}/" dcase18_aligned_fold${fold}.yml
      sed -i "s|save_folder: .*|save_folder: './dcase18_aligned_fold${fold}'|" dcase18_aligned_fold${fold}.yml
      sed -i "s|pretrained_model_path: .*|pretrained_model_path: './dcase18_aligned_fold${fold}/pretrain_model_dcase18.pth'|" dcase18_aligned_fold${fold}.yml
      python main.py --config dcase18_aligned_fold${fold}.yml \
        2>&1 | tee ../experiment/foac_exp/pretrain_fold${fold}.log
    done

    注: 实验脚本 (FP1-4) 内部设 test=False 自行训练+评估, 只需 FP0 产出 pretrain_model.
        若需单独跑 baseline (不走实验脚本):
          pretrain: true  test: false → python main.py  (预训练)
          pretrain: false test: false → python main.py  (meta-train)
          pretrain: false test: true  → python main.py  (评估)


  FP1 ── 消融实验 (6配置 CIAM/PAM/NPM on/off, 4-fold)
  ───────────────────────────────────────────────────────────
    cd /coding/FOAC-AIFP

    # 全量: 6配置 × 4fold = 24轮训练 (每轮 ~80 epochs)
    python foac_exp_ablation.py --dataset DCASE18 --fold all \
      2>&1 | tee ../experiment/foac_exp/ablation/train_dcase18.log
    mv foac_exp_ablation_results.json ../experiment/foac_exp/ablation/results_dcase18.json

    # 单 fold 快速验证:
    python foac_exp_ablation.py --dataset DCASE18 --fold 1 --quick \
      2>&1 | tee ../experiment/foac_exp/ablation/quick_fold1.log


  FP2a ── Way-Shot 扫描 (5way/6way × 1/5/10shot, 4-fold)
  ───────────────────────────────────────────────────────────
    cd /coding/FOAC-AIFP

    # 全量: 6组合 × 4fold
    python foac_exp_way_shot.py --dataset DCASE18 --fold all \
      2>&1 | tee ../experiment/foac_exp/wayshot/train_dcase18.log
    mv foac_exp_way_shot_results.json ../experiment/foac_exp/wayshot/results_dcase18.json

    # 快速: 仅 5w1s+6w5s, 1 fold
    python foac_exp_way_shot.py --dataset DCASE18 --fold 1 --quick \
      2>&1 | tee ../experiment/foac_exp/wayshot/quick_fold1.log


  FP2b ── Openness 扫描 (open2+open4, 4-fold)
  ───────────────────────────────────────────────────────────
    cd /coding/FOAC-AIFP

    # 全量:
    python foac_exp_openness.py --dataset DCASE18 --fold all \
      2>&1 | tee ../experiment/foac_exp/openness/train_dcase18.log
    mv foac_exp_openness_results.json ../experiment/foac_exp/openness/results_dcase18.json

    # 快速:
    python foac_exp_openness.py --dataset DCASE18 --fold 1 --quick \
      2>&1 | tee ../experiment/foac_exp/openness/quick_fold1.log


  FP3a ── 跨域评估 (依赖 FP1 checkpoint)
  ───────────────────────────────────────────────────────────
    cd /coding/FOAC-AIFP

    # DCASE18 → TAU22
    python foac_exp_cross_domain.py --source DCASE18 --target TAU22 --source_fold 1 \
      2>&1 | tee ../experiment/foac_exp/cross_domain/train_dcase18_tau22.log

    # DCASE18 → TAU19
    python foac_exp_cross_domain.py --source DCASE18 --target TAU19 --source_fold 1 \
      2>&1 | tee ../experiment/foac_exp/cross_domain/train_dcase18_tau19.log

    # TAU22 → DCASE18
    python foac_exp_cross_domain.py --source TAU22 --target DCASE18 --target_fold 1 \
      2>&1 | tee ../experiment/foac_exp/cross_domain/train_tau22_dcase18.log

    # TAU19 → DCASE18
    python foac_exp_cross_domain.py --source TAU19 --target DCASE18 --target_fold 1 \
      2>&1 | tee ../experiment/foac_exp/cross_domain/train_tau19_dcase18.log

    # 收集全部4方向结果:
    mv foac_exp_cross_domain_results.json ../experiment/foac_exp/cross_domain/results_dcase18.json

    注: FOAC-AIFP 跨域脚本一次只跑一对方向; 需逐对执行。


  FP3b ── 复杂度 (同 experiment_list.txt, 无需重跑)
  ───────────────────────────────────────────────────────────
    # DCASE18 使用相同模型架构, 复杂度数据与 TAU 相同, 复用即可。


  FP3c ── 统计检验 (依赖 FP1 消融结果)
  ───────────────────────────────────────────────────────────
    cd /coding/FOAC-AIFP
    python foac_exp_statistical.py --results ../experiment/foac_exp/ablation/results_dcase18.json \
      2>&1 | tee ../experiment/foac_exp/statistical/train_dcase18.log


  FP4 ── t-SNE 可视化
  ───────────────────────────────────────────────────────────
    cd /coding/FOAC-AIFP

    # 单 fold
    python foac_exp_tsne.py --config dcase18_aligned.yml --fold 1 --compare_ablation \
      2>&1 | tee ../experiment/foac_exp/tsne/train_dcase18_fold1.log

    # 4 fold 分别生成 (文件名自动含 fold):
    for fold in 1 2 3 4; do
      python foac_exp_tsne.py --config dcase18_aligned.yml --fold $fold \
        2>&1 | tee ../experiment/foac_exp/tsne/train_dcase18_fold${fold}.log
    done

================================================================================
五、注意事项
================================================================================

  1. fold=all 运行时间: 单脚本 ×4fold, 全量跑完约需 4× 原 TAU 时间。
     建议先在单 fold 上 --quick 验证, 确认无误后再跑 --fold all。

  2. DCASE18 类别数 (5+4) 与 TAU (6+4) 不同:
     - FOAC-AIFP: train_classes=5, n_ways=3, test_n_ways=5, test_n_open_ways=4
     - Episodic: base_classes=[0-4], unknown_classes=[5-8], N_way=4

  3. Pretrain 必须先跑: DCASE18 fold 间 session 隔离,
     不同 fold 的 pretrain 模型不能复用。

  4. 跨域脚本一次只评估一对方向, 需逐对执行。

  5. 脚本已修改支持 DCASE18 (2026-05-13):
     - FOAC-AIFP: foac_exp_{ablation,way_shot,openness,cross_domain,tsne}.py
     - Episodic: episodic_exp_{ablation,way_shot,openness,cross_domain,tsne}.py
     - complexity 和 statistical 脚本无需修改 (数据集无关 / 接收 JSON)
