一、项目代码体系概述
────────────────────────────────────────────────────────────────────────────────
本项目存在两套并行的实验系统：

【系统A】FOAC-AIFP (论文方法，ResNet18 backbone)
  代码：FOAC-AIFP/ 目录
  入口：FOAC-AIFP/main.py
  训练：FOAC-AIFP/trainers/trainer.py + C2_Net_train.py
  模型：models/Network.py (My_Net) — 含 PGFC/PGOC/PAPN 等核心组件
  数据集：TAU22.py, TAU19.py (以及 FMC.py, nsynth.py, librispeech.py 可用)
  配置：default.yml, tau19_aligned.yml, tau22_aligned.yml
  特点：端到端训练，原型网络+注意力信息融合，是论文的核心方法

【系统B】Episodic Trainer (对比基线，YAMNet/PANNs/AST backbone)
  代码：/coding/episodic_trainer.py, episodic_trainer_tau19.py
  入口：直接运行 (main函数)
  特点：三阶段流水线（特征预提取 → 元训练 → OSR校准）
  实验：22+个实验目录 (experiment/yamnet_fewshot_osr*), pann, ast 等
  作用：作为对比方法的基线，已探索多种 OSR 策略

五、需要编写的代码/脚本清单
================================================================================

  [1] ablation_runner.py — 消融实验运行脚本
      - 修改模型支持组件 on/off
      - 自动遍历所有组合并记录结果

  [2] way_shot_sweep.py — Way/Shot 参数扫描脚本
      - 遍历 N ∈ {2,3,4,5,6}, K ∈ {1,3,5,7,10}
      - 记录 Acc, AUROC, OSR

  [3] openness_sweep.py — 开放度影响分析脚本
      - 遍历 n_open_ways ∈ {1,2,3,4}
      - 记录 AUROC 变化

  [4] statistical_test.py — Friedman + Nemenyi 检验脚本
      - 输入：各方法在各数据集上的结果矩阵
      - 输出：p-value, 临界差图

  [5] complexity_analysis.py — 复杂度分析脚本
      - 使用 thop/fvcore 计算 MACs
      - 计时推理时间
      - 统计参数量

  [6] cross_domain_eval.py — 跨域评估脚本
      - 加载一个数据集训练的模型
      - 在另一个数据集上评估

  [7] tsne_foac.py — FOAC-AIFP 特征空间的 t-SNE 可视化
      - 提取 FOAC-AIFP 的特征
      - 绘制已知类/未知类分布对比图

六、关键风险与注意事项
================================================================================

  1. TAU22 aligned 正在训练中，需确认训练完成后再做后续实验
  2. TAU19 aligned 的 ACC=100% 看起来可能存在数据泄露或过拟合问题
     → 需要仔细检查 train/test 划分是否严格分离
  3. FOAC-AIFP (ResNet18) 和 Episodic Trainer (YAMNet) 使用不同 backbone
     → 论文中需明确区分，不能直接对比
     → 建议论文以 FOAC-AIFP 为主体，Episodic Trainer 作为附录/补充
  4. 参考论文用了 3 个数据集，本项目目前只有 2 个同域数据集
     → 审稿人可能质疑泛化性，建议至少补 1 个跨域数据集
  5. 对比方法 (FEAT, MET 等) 的实现需要找到原始代码库
     → 可以从 GitHub 获取，但需确认音频域适配
