================================================================================
四、执行计划
================================================================================

  P0  ── 已完成。TAU22 aligned best@ep78, TAU19 aligned 已完成
        推荐 checkpoint: TAU22 max_auroc (AUROC=53.50), TAU19 max_auroc (AUROC=46.89)

  ── Episodic Trainer 执行顺序 ── (输出统一至 experiment/episodic_exp/)
  所有脚本支持 --output_dir 自定义路径，默认 experiment/episodic_exp

  初始化:
        mkdir -p experiment/episodic_exp/{ablation,wayshot,openness,complexity,cross_domain,statistical,tsne}

  EP1 ── 消融实验 (最能体现论文贡献，优先跑)
        cd /coding && python episodic_exp_ablation.py 2>&1 | tee experiment/episodic_exp/ablation/train.log

  EP2 ── Way-Shot / Openness 扫描
        cd /coding && python episodic_exp_way_shot.py 2>&1 | tee experiment/episodic_exp/wayshot/train.log
        cd /coding && python episodic_exp_openness.py 2>&1 | tee experiment/episodic_exp/openness/train.log

  EP3 ── 跨域 / 复杂度 / 统计检验 (依赖 EP1/EP2 结果)
        cd /coding && python episodic_exp_cross_domain.py --all 2>&1 | tee experiment/episodic_exp/cross_domain/train.log
        cd /coding && python episodic_exp_complexity.py --all_ablation 2>&1 | tee experiment/episodic_exp/complexity/train.log
        cd /coding && python episodic_exp_statistical.py --results experiment/episodic_exp/ablation/results.json 2>&1 | tee experiment/episodic_exp/statistical/train.log

  EP4 ── t-SNE 可视化 + 论文制表
        cd /coding && python episodic_exp_tsne.py --compare_ablation 2>&1 | tee experiment/episodic_exp/tsne/train.log

  ── FOAC-AIFP 执行顺序 ── (输出统一至 experiment/foac_exp/)
  注: 脚本 results.json 硬编码在 FOAC-AIFP/ 根目录，通过 shell 移动到统一目录
      checkpoint 仍在 save_folder 衍生路径 (tau22_aligned_ablation/ 等)

  初始化:
        mkdir -p experiment/foac_exp/{ablation,wayshot,openness,complexity,cross_domain,statistical,tsne}

  FP1 ── 消融实验
        cd /coding/FOAC-AIFP && python foac_exp_ablation.py 2>&1 | tee ../experiment/foac_exp/ablation/train.log && mv foac_exp_ablation_results.json ../experiment/foac_exp/ablation/results.json

  FP2a ── Way-Shot 扫描
        cd /coding/FOAC-AIFP && python foac_exp_way_shot.py --dataset all 2>&1 | tee ../experiment/foac_exp/wayshot/train.log && mv foac_exp_way_shot_results.json ../experiment/foac_exp/wayshot/results.json

  FP2b ── Openness 扫描
        cd /coding/FOAC-AIFP && python foac_exp_openness.py --dataset all 2>&1 | tee ../experiment/foac_exp/openness/train.log && mv foac_exp_openness_results.json ../experiment/foac_exp/openness/results.json

  FP3a ── 跨域 (依赖 FP1/FP2 结果)
        cd /coding/FOAC-AIFP && python foac_exp_cross_domain.py --all 2>&1 | tee ../experiment/foac_exp/cross_domain/train.log && mv foac_exp_cross_domain_results.json ../experiment/foac_exp/cross_domain/results.json

  FP3b ── 复杂度
        cd /coding/FOAC-AIFP && python foac_exp_complexity.py --all_ablation 2>&1 | tee ../experiment/foac_exp/complexity/train.log && mv foac_exp_complexity_results.json ../experiment/foac_exp/complexity/results.json

  FP3c ── 统计检验 (依赖 FP1)
        cd /coding/FOAC-AIFP && python foac_exp_statistical.py --results ../experiment/foac_exp/ablation/results.json 2>&1 | tee ../experiment/foac_exp/statistical/train.log

  FP4 ── t-SNE 可视化
        cd /coding/FOAC-AIFP && python foac_exp_tsne.py --compare_ablation 2>&1 | tee ../experiment/foac_exp/tsne/train.log
