================================================================================
四、执行计划
================================================================================

  P0  ── TAU22 aligned 训练完成 → 确定最佳 checkpoint

  P1  ── 运行消融实验 (最能体现论文贡献)
        cd FOAC-AIFP && python foac_exp_ablation.py --all
        cd /coding   && python episodic_exp_ablation.py --all

  P2  ── Way-Shot / Openness 扫描
        foac_exp_way_shot.py --dataset all
        foac_exp_openness.py --dataset all
        (episodic 版本同上)

  P3  ── 跨域 / 复杂度 / 统计检验
        foac_exp_cross_domain.py --all
        foac_exp_complexity.py --all_ablation
        foac_exp_statistical.py --results xxx.json

  P4  ── t-SNE 可视化 + 论文制表
        foac_exp_tsne.py --compare_ablation
