OSR17 重训行动指南 — 基于最新文献启发的全面重构
================================================

Baseline: FOAC-AIFP (华南理工, Li & Tan)
  代码位置: /coding/FOAC-AIFP/
  已有模型: save_tau22/ (pretrain + 3个best模型: acc/auroc/fscore)
  Backbone: ResNet-18 (ImageNet预训练 → Log-Mel频谱 → 512-dim)
  OSR方法: RPL互反点预训练 + NPM开放集生成器 + (N+1)-way分类
  训练策略: 两阶段 (RPL/GCPL预训练 → Episodic元训练)
  评估指标: ACC (闭集), AUROC (开放集), F-score
  Episode配置: 2-way 5-shot 15-query (TAU22仅6基类，受限)

目标: 在FOAC-AIFP baseline之上，融合SupCon特征学习、可学习阈值、
      互反点增强、Curriculum OOD等思想，实现OSR性能跃升
前提: 需从头训练完整 Phase 0→1→2→3 流水线

与FOAC-AIFP的关键区别:
  1. Backbone: YAMNet(64-dim) vs ResNet-18(512-dim) → 我们的更轻量
  2. 特征学习: SupCon(有监督对比) vs RPL+GCPL → 更强的类间分离
  3. OSR策略: 多方法融合 vs 单一(N+1)-way → 更鲁棒
  4. Episode规模: 5-way vs 2-way → 我们评估更充分

实施路径: osr17a (特征升级+可学习阈值) → osr17b (互反点+curriculum OOD) → osr17c (不确定性建模)

────────────────────────────────────────
1.1 Phase 0a: SupCon替代SimCLR
────────────────────────────────────────

原理: SimCLR不知道类别标签，同类样本可能被推远。
      SupCon利用已知类标签(仅base classes)，确保同类紧凑、异类远离。
      特征空间越紧凑，feature_mahalanobis的TPR天然越高。
      FOAC-AIFP的RPL也利用了类标签做互反点，但RPL是分类器级别的，
      SupCon是特征级别的，更根本。

当前代码位置: ContrastivePretrainer (约L600-850)
当前使用 NT-Xent (SimCLR) loss:
  sim_matrix = F.cosine_similarity(z1.unsqueeze(1), z2.unsqueeze(0), dim=2)
  loss = nt_xent_loss(sim_matrix, temperature)

更改方向:

Step 1: 修改ContrastivePretrainer.train() (约L700-830):

  # 当前: 完全无监督，batch内所有样本互为负例
  # 改为: 有监督对比学习，利用base_classes标签

  # 新增参数:
  supervised_contrastive = True  # True=SupCon, False=SimCLR(回退)

  # 构造batch时同时返回标签:
  # _get_batch() 已返回 (aug1, aug2, labels)
  # labels 只对 base_classes 有效，unknown 标记为 -1

  # SupCon loss 实现:
  def supcon_loss(features, labels, temperature=0.1, mask_unknown=True):
      """
      features: (2*B, D) - 两个augmentation拼接
      labels: (B,) - 类别标签，-1表示不参与
      temperature: 温度参数
      """
      device = features.device
      batch_size = labels.shape[0]

      # 拼接两个view的标签
      labels = labels.repeat(2)  # (2B,)
      if mask_unknown:
          valid_mask = labels >= 0  # 排除unknown类(-1)
      else:
          valid_mask = torch.ones(2 * batch_size, dtype=torch.bool, device=device)

      # 同类mask: label_i == label_j 且 i≠j 且 都valid
      label_mask = labels.unsqueeze(0) == labels.unsqueeze(1)  # (2B, 2B)
      label_mask = label_mask & valid_mask.unsqueeze(1) & valid_mask.unsqueeze(0)
      diag_mask = ~torch.eye(2 * batch_size, dtype=torch.bool, device=device)
      label_mask = label_mask & diag_mask  # 排除自身

      # 负例mask: 都valid 且 不是同类
      neg_mask = ~label_mask & diag_mask & valid_mask.unsqueeze(1)

      # 计算相似度
      sim = F.cosine_similarity(features.unsqueeze(1), features.unsqueeze(0), dim=2) / temperature

      # 对每个anchor，如果有同类正例，计算SupCon loss
      has_positive = label_mask.sum(dim=1) > 0
      if has_positive.sum() == 0:
          # fallback to SimCLR if no pairs
          return nt_xent_loss(features[:batch_size], features[batch_size:], temperature)

      # log-sum-exp trick
      exp_sim = torch.exp(sim) * diag_mask
      log_prob = sim - torch.log(exp_sim.sum(dim=1, keepdim=True) + 1e-8)

      # 只对有正例的anchor计算loss
      mean_log_prob = (log_prob * label_mask.float()).sum(dim=1) / (label_mask.float().sum(dim=1) + 1e-8)

      loss = -mean_log_prob[has_positive].mean()
      return loss

  # 训练循环修改:
  # Phase 0a前半(150 epochs): SimCLR (无监督，所有类参与，学习通用特征)
  # Phase 0a后半(150 epochs): SupCon (base_classes标签，学习判别性特征)
  # 这样既保留SimCLR的泛化性，又获得SupCon的判别力

  if epoch <= 150:
      loss = nt_xent_loss(z1, z2, temperature)
  else:
      features = torch.cat([z1, z2], dim=0)
      loss = supcon_loss(features, batch_labels, temperature)

  # TAUDataset已有get_label()方法

────────────────────────────────────────
1.2 可学习OSR阈值 (LearnableThreshold)
────────────────────────────────────────

原理: 当前OSRCalibrator.calibrate()用固定percentile设阈值，
      calib集上表现好但test集下降严重(已观察到此问题)。
      将阈值作为可学习参数，在episodic训练中优化。
      FOAC-AIFP没有这个问题因为它用(N+1)-way直接分类，无需阈值。
      我们的优势: 阈值方法更灵活，可以后处理调整。

代码位置: 新增类 + 修改EpisodicTrainer.train_episode

新增类 (在EpisodicFlowClassifier之后):

  class LearnableOSRThreshold(nn.Module):
      """可学习的OSR阈值，替代固定percentile"""
      def __init__(self, num_scores: int = 1, init_value: float = 0.0):
          super().__init__()
          self.thresholds = nn.Parameter(torch.full((num_scores,), init_value))
          self.temperature = nn.Parameter(torch.tensor(1.0))

      def forward(self, scores: torch.Tensor) -> torch.Tensor:
          """将连续分数转为known/unknown概率"""
          return torch.sigmoid((scores - self.thresholds) * self.temperature.abs())

      def get_threshold(self) -> float:
          return self.thresholds.item()

在EpisodicFlowClassifier中添加:
  self.osr_threshold = LearnableOSRThreshold(num_scores=1, init_value=0.0)

在EpisodicTrainer.train_episode中添加:
  with torch.no_grad():
      known_scores = compute_mahalanobis(query_feats, prototypes)
      if ood_feats is not None:
          unknown_scores = compute_mahalanobis(ood_feats, prototypes)

  known_probs = self.flow_classifier.osr_threshold(known_scores)
  unknown_probs = self.flow_classifier.osr_threshold(unknown_scores)
  L_threshold = -torch.log(known_probs + 1e-8).mean()
  L_threshold += -torch.log(1 - unknown_probs + 1e-8).mean()

  loss += 0.1 * L_threshold

在OSRCalibrator.evaluate_osr中使用学习到的阈值:
  learned_threshold = self.flow_classifier.osr_threshold.get_threshold()

2.1 互反点学习 (Reciprocal Point, 来自ARPL)
────────────────────────────────────────

原理: FOAC-AIFP的RPL预训练已经用了互反点思想！但它是在ResNet-18 backbone
      的预训练阶段学的，且互反点与backbone耦合。
      我们的方法: 在episodic训练中学习互反点，与YAMNet特征适配。
      优势: 互反点随episode动态适应，更灵活。

在EpisodicFlowClassifier中添加:

  # __init__:
  self.num_max_classes = 20
  self.reciprocal_points = nn.Parameter(
      torch.randn(self.num_max_classes, input_dim) * 0.1
  )

  # 新增方法:
  def compute_reciprocal_loss(self, features, prototypes, labels):
      B, D = features.shape
      N = prototypes.shape[0]
      R = self.reciprocal_points[:N]
      R_assigned = R[labels]

      # 已知样本应远离互反点
      dist_to_reciprocal = ((features - R_assigned) ** 2).sum(dim=1)
      L_push = -torch.log(dist_to_reciprocal + 1.0).mean()

      # 互反点多样化正则
      proto_R_sim = F.cosine_similarity(
          prototypes.unsqueeze(1), R.unsqueeze(0), dim=2)
      L_diverse = -proto_R_sim.mean()

      return L_push + 0.1 * L_diverse

  # 新增OSR评分方法:
  def score_reciprocal(self, features, prototypes):
      N = prototypes.shape[0]
      R = self.reciprocal_points[:N]
      dist_proto = torch.cdist(features, prototypes, p=2).min(dim=1).values
      dist_R = torch.cdist(features, R, p=2).min(dim=1).values
      return -dist_proto + dist_R  # known高, unknown低

在EpisodicTrainer.train_episode中加入:
  L_reciprocal = self.flow_classifier.compute_reciprocal_loss(
      query_feats, prototypes, query_labels)
  loss += 0.05 * L_reciprocal

在OSRCalibrator中新增 reciprocal 评分方法。

2.2 3级Curriculum OOD (来自CROCO/PEELER)
────────────────────────────────────────

原理: FOAC-AIFP的NPM模块通过交叉注意力从基类权重生成"假类中心"作为
      (N+1)-way的未知类原型。这是一种全局策略，不随训练进度变化。
      我们的方法: 3级递进难度的伪未知，像课程学习一样逐步提升。
      优势: 训练早期用简单OOD稳定分类器，后期用对抗OOD增强鲁棒性。

在EpisodicTrainer中替换现有OOD生成逻辑:

  def generate_curriculum_ood(self, prototypes, features, episode_num, max_episodes):
      progress = min(episode_num / max_episodes, 1.0)

      if progress < 0.33:
          # Level 1: Easy — 原型间插值 + 噪声
          return self._sample_boundary_ood(prototypes, num_samples=15)

      elif progress < 0.66:
          # Level 2: Medium — Hard Negative组合
          N = prototypes.shape[0]
          num_samples = 15
          ood_feats = []
          for _ in range(num_samples):
              n_mix = np.random.randint(2, min(N, 4))
              chosen = np.random.choice(N, n_mix, replace=False)
              weights = np.random.dirichlet(np.ones(n_mix) * 0.5)
              mixed = sum(w * prototypes[c] for w, c in zip(weights, chosen))
              mixed += torch.randn_like(mixed) * 0.1
              ood_feats.append(mixed)
          return torch.stack(ood_feats)

      else:
          # Level 3: Hard — 对抗性生成
          num_samples = 15
          ood_feats = []
          for _ in range(num_samples):
              x = prototypes.mean(dim=0) + torch.randn(prototypes.shape[1], device=self.device) * 0.5
              x = x.clone().detach().requires_grad_(True)
              optimizer_adv = torch.optim.SGD([x], lr=0.05)
              for _ in range(5):
                  log_probs = self.flow_classifier.classify(x.unsqueeze(0), prototypes)
                  entropy = -(log_probs.exp() * log_probs).sum()
                  (-entropy).backward()
                  optimizer_adv.step()
                  optimizer_adv.zero_grad()
              ood_feats.append(x.detach())
          return torch.stack(ood_feats)

  def _sample_boundary_ood(self, prototypes, num_samples=15):
      N = prototypes.shape[0]
      ood_feats = []
      for _ in range(num_samples):
          i, j = np.random.choice(N, 2, replace=False)
          alpha = np.random.beta(0.5, 0.5)
          mixed = alpha * prototypes[i] + (1 - alpha) * prototypes[j]
          mixed += torch.randn_like(mixed) * 0.2
          ood_feats.append(mixed)
      return torch.stack(ood_feats)

三、osr17c: 原型不确定性建模 (优先级5)
════════════════════════════════════════════════════════════════════

前提: osr17b完成
预期收益: K=1~3 shot时收益大，K=5时也有边际收益
工作量: 中
预计耗时: ~2h

原理: FOAC-AIFP的PAM模块通过余弦相似度加权聚合原型，本质上是一种
      基于样本质量的加权平均。但它没有显式建模不确定性。
      我们的方法: 输出分布参数(均值+标准差)，用精度加权的马氏距离。

在EpisodicFlowClassifier.classify()中修改原型计算:

  # 当前:
  prototype = support_feats[mask].mean(dim=0)

  # 改为分布原型:
  proto_mean = support_feats[mask].mean(dim=0)
  if support_feats[mask].shape[0] > 1:
      proto_std = support_feats[mask].std(dim=0).clamp(min=0.01)
  else:
      proto_std = torch.ones_like(proto_mean) * 0.1  # K=1时给较大不确定性

  # 精度加权距离:
  proto_precision = 1.0 / (proto_std ** 2)
  diff = query_feats - proto_mean
  weighted_dist = (diff ** 2 * proto_precision).sum(dim=1)

注意: 这会改变classify()的接口，需同步修改EpisodicTrainer和OSRCalibrator。

七、osr15/osr16失败的教训 (设计osr17时必须避免)
════════════════════════════════════════════════════════════════════

1. 不要联合训练flow+分类器 (osr15教训)
   osr17: 不使用flow作为主OSR方法，用feature_mahalanobis+互反点

2. 特征质量是OSR上限 (osr13→osr15的经验)
   → osr17优先投入SupCon特征升级，而非继续优化OSR head

3. 阈值不能只靠校准集percentile (calib→test下降)
   → osr17使用可学习阈值，在训练中优化

4. 伪未知样本质量决定ood_head上限
   → osr17使用3级curriculum OOD，而非简单mixup

5. 简单方法优先
   osr13的z_consistency 20.22% 已经是最好的结果
   复杂的flow方法(osr15)反而崩溃到3.74%
   → osr17优先改特征(SupCon)和阈值(可学习)，这些改动风险最小
