  PANN OSR1 结果分析

  核心发现：
  1. **特征质量是 OSR 性能的决定因素**
     → feature_mahalanobis: 11.87% → 21.33% (+79%)
     → PANN 全局特征显著优于 YAMNet 局部特征
     → 这是唯一可靠的 OSR 方法

  2. **Base 分类严重 underfitting**
     → YAMNet 83.60% vs PANN 68.33% (-15%)
     → PANN fine-tune 不充分（仅 20 epochs, 2 层）
     → 需要更强训练策略

  3. **Novel 分类改善验证 PANN 优势**
     → 47.93% vs 44.27% (+3.7%)
     → 全局时序理解对新类泛化更好

  4. **z/flow 方法全面失效**
     → z_consistency: 20% → 6% (崩溃)
     → flow_hybrid: <8% (不可靠)
     → 复杂方法不稳定，不应作为主要 OSR 策略

  结论：
  - **OSR = 特征质量 + 简单方法** (feature_mahalanobis)
  - **PANN 需要更强 fine-tune** (修复 Base 分类)
  - **放弃复杂方法优化** (z/flow 不可靠)

  当前计划：pann_osr2

  策略转变：从复杂方法优化 → 基础能力强化

  实施步骤：

  1. **强化 PANN fine-tune（修复 Base 分类）**
     - Phase 0b epochs: 20 → 50
     - 解冻层: conv_block4-6 (3层 → 4层, 增加 conv_block3)
     - Backbone LR: 5e-6 → 2e-6 (更慢更稳)
     - FC LR: 5e-5 → 3e-5
     - 目标: Base 5-shot >78%

  2. **简化 OSR 方法（仅保留可靠的）**
     - 主方法: feature_mahalanobis (21.33% TPR, 稳定)
     - 辅助: 无（放弃 z/flow 优化）
     - 评估: 仅 feature_mahalanobis
     - 目标: feat_mahal TPR >22%

  3. **Phase 2 简化配置**
     - 移除 L_gaussian, L_density, L_entropy
     - 仅保留基础分类 loss: CE + L_separation
     - 移除 OOD stop-gradient
     - 训练更稳定，收敛更快

  4. **配置修改**
     - backbone: panns_cnn14
     - experiment_dir: experiment/pann_fewshot_osr2
     - Phase 0b epochs: 50
     - backbone_unfreeze_layers: ['conv_block3', 'conv_block4', 'conv_block5', 'conv_block6']
     - backbone_lr: 2e-6
     - fc_lr: 3e-5

  5. **移除的组件**
     - EpisodicFlowClassifier → 简化为 PrototypicalNetwork
     - GMMBoundarySampler → 简化为随机采样
     - OOD stop-gradient → 移除
     - 所有 z/flow loss → 移除

  预期结果：
  - Base 5-shot: >78% (修复 underfitting)
  - Novel 5-shot: >50% (保持 PANN 优势)
  - feat_mahal TPR: >22% (保持稳定)
  - 训练时间: ~50% 减少 (移除复杂组件)

  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  PANN OSR2 实际结果

  实际配置：
    - Phase 0b: 50 epochs, conv_block3-6 unfrozen
    - backbone_lr: 2e-6, fc_lr: 3e-5
    - use_flow: False (简化配置)

  实际结果：
    - Base 5-shot: 69.59% (target: 78%, gap: -8.4%)
    - Novel 5-shot: 40.97%
    - feat_mahal TPR: 21.33% (稳定)
    - ood_head TPR: 3.65% (失效)

  关键发现：
    1. **Base 分类仍然 underfitting** (69.59% vs 78% target)
       → PANN fine-tune 策略未达预期
       → 50 epochs + 4层解冻仍不足

    2. **OSR 性能稳定** (feat_mahal 21.33%)
       → 验证了简化策略的有效性
       → 特征质量不是瓶颈

    3. **OOD Head 失效** (TPR 3.65%)
       → 可能需要 Phase 2 训练优化

  决策：切换至 AST backbone（更强的预训练）

完成后决策（已执行）：
  - Base 5-shot = 69.59% (<75%) → 切换至 AST backbone
  - feat_mahal TPR = 21.33% (<25%) → 特征质量未突破
