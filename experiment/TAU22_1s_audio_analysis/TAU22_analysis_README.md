# TAU 城市声学场景数据集分析报告

## 一、数据集概述

本报告基于 TAU-urban-acoustic-scenes-2022-mobile 数据集的完整分析，涵盖 7 个维度的可视化图表，旨在帮助研究者和工程师深入理解数据特点，并为开放集识别（Open-Set Recognition）与聚类模型的训练提供数据层面的依据和指导。

### 1.1 数据集基本信息

| 属性 | 说明 |
|------|------|
| 任务类型 | 城市声学场景分类（10 类） |
| 已知类（0-5） | airport、shopping_mall、metro_station、street_pedestrian、public_square、street_traffic |
| 未知类（6-9） | tram、bus、metro、park |
| 采样率 | 16000 Hz |
| 音频时长 | 1 秒切片 |
| 特征提取 | Log-Mel 频谱图（64 mel bins、400 n_fft、160 hop_length） |
| 评估场景 | 开放集识别：训练阶段仅接触已知类，测试阶段需识别已知类并拒绝未知类 |

---

## 二、按图表详细分析

### 2.1 类别分布分析（01_class_distribution.png）

**图表核心发现：**

该图表展示了训练集、校准集和评估集三个数据划分中 10 个类别的样本分布情况。通过红色虚线将已知类（0-5）与未知类（6-9）分隔开来。

**数据分布特点：**

在训练集中，仅包含 6 个已知类，每个类别各有 2500 个样本，总计 15000 个样本。校准集和评估集则包含全部 10 个类别，每个类别各有 1000 个样本，总计各 10000 个样本。值得注意的是，训练集和校准/评估集之间存在一个本质差异：训练阶段模型完全无法接触未知类（tram、bus、metro、park）的数据，这正是开放集识别任务的核心挑战所在。

**类别平衡性评估：**

在训练集内部，6 个已知类别的样本量完全相等（均为 2500 个），呈现出完美的均衡分布。校准集和评估集中，10 个类别的样本量同样完全相等（均为 1000 个）。这种设计排除了样本量差异对实验结果的干扰，使得模型性能评估能够真实反映其对不同类别的区分能力，特别是对未知类的检测能力。

**对开放集识别的启示：**

由于训练集中未知类样本量为零，模型在学习阶段只能建立对已知类别的内部表示。这意味着模型必须具备识别“陌生模式”的能力，而非简单地记忆训练数据的类别边界。开放集识别方法需要能够检测与已知分布显著偏离的样本，例如基于重构误差、能量分数、不确定性估计或对比学习的方法。

### 2.2 波形统计特征分析（02_waveform_stats.png）

**图表核心发现：**

该图表从时域角度分析了音频波形的三个关键统计指标：RMS 能量（反映信号平均功率）、峰值幅度（反映瞬时最大强度）和零交叉率（反映信号变化频率）。

**已知类与未知类的波形差异：**

在 RMS 能量方面，已知类中的 airport、shopping_mall 和 public_square 表现出较低的能量分布，而 metro_station 和 street_traffic 能量较高且波动范围较大。未知类中，tram、bus、metro 三个交通类别的能量显著高于大部分已知类，park 则是一个明显的例外——其能量和幅度均为所有类别中最低的，甚至低于大多数已知类。

在零交叉率方面，这是区分已知类和未知类最有效的单一统计特征。已知类的零交叉率普遍偏高（大多数中位数在 0.05 以上），说明这些场景包含更多高频成分或杂乱的背景人声。未知类的零交叉率普遍偏低（中位数大多在 0.05 以下），特别是 tram、bus、park 表现尤为明显。这意味着已知类在频谱分布上可能包含更多的高频噪声或人声成分，而未知交通场景则更多表现为低频、平稳的机械声。

**类别混淆风险分析：**

airport 和 shopping_mall 的三个统计特征几乎完全重合，仅凭时域统计特征很难区分这两个类别。street_traffic（已知类）与 tram（未知类）在 RMS 能量上非常接近，但两者的零交叉率存在明显差异——street_traffic 零交叉率高、tram 零交叉率低，这一特性可用于区分这对容易混淆的类别。bus 和 metro 两个未知类在能量和零交叉率上存在较多重叠，可能需要更复杂的频域特征来进一步区分。

**对模型训练的启示：**

虽然简单时域特征不足以完成细粒度分类，但零交叉率特征可作为开放集检测的辅助指标。能量差异本身不是可靠的分类依据，因为同一类别内的能量变化范围很大。交通类场景（无论已知还是未知）普遍具有更高的能量和更低的零交叉率，这一规律可用于快速预筛选。

### 2.3 平均 Mel 频谱图分析（05_average_mel_spectrograms.png）

**图表核心发现：**

该组图表以平均 Log-Mel 频谱图的形式，直观展示了 10 个声学场景在时间-频率域的典型模式。频谱图的横轴表示时间，纵轴表示 Mel 频率（低频在底部、高频在顶部，颜色越亮表示能量越强）。

**各类别频谱模式特点：**

airport（机场）的能量主要集中在低频段（512 Hz 以下），中高频段有较为均匀但较弱的分布。时间结构上非常平滑，反映了机场中持续的背景机械噪声和远处的嘈杂人声。shopping_mall（购物中心）与机场类似，但中频能量略高且纹理更粗糙，这反映了更近距离、更频繁的人声交流和脚步声等随机瞬态声音。metro_station（地铁站）表现为极低的低频能量，且在 1024 Hz 附近有一条明显的水平能量带，这代表了车站内持续的通风系统噪声或轨道共振。

street_pedestrian（步行街）的能量分布较广，低频依然占主导，但中高频的衰减比室内环境更慢。时间上表现出一定的起伏，对应于行人经过时的声音变化。public_square（公共广场）与步行街非常相似，但高频部分能量略低，空间感更开阔。street_traffic（街道交通）具有非常明显的水平条带特征，在 1024 Hz 左右有持续的高能量带，这是典型的内燃机引擎工作谐波特征。整体能量随频率升高而稳步下降。

tram（有轨电车）的低频能量最为密集，且在时间轴上表现出轻微的垂直条纹（脉冲感），这对应于车轮撞击轨道接缝的节奏性声音。bus（巴士）的频谱模式与街道交通相似，但中低频能量更厚重，反映了大型柴油引擎更沉闷的轰鸣声。metro（地铁内）的低频能量极强且在整个时间轴上高度一致，中高频非常暗，说明地铁车厢内部对高频噪声有较好的屏蔽。park（公园）是所有类别中最独特的，中高频能量显著低于其他所有类别，能量几乎完全压缩在极低频段，反映了公园安静、缺乏机械噪声的特点。

**类别相似性与聚类分析：**

从频谱模式来看，可以归纳为几个高相似度组：交通组（包括 street_traffic、bus、metro_station）都以持续的发动机中低频噪声为特征；室内公共空间组（包括 airport、shopping_mall）体现了开阔室内空间的混响背景音；室外步行组（包括 street_pedestrian、public_square）反映了开阔地带弥散的背景噪声。在独特性方面，park 最为独特，是唯一一个高频几乎完全空白的类别；metro 和 tram 虽然都属于轨道交通，但 metro 的低频更纯净、更持续，而 tram 带有明显的机械撞击节奏感。

**对模型设计的启示：**

低频能量强度和频谱时间结构模式是区分声学场景的关键特征。交通类场景普遍表现出水平能量带（持续的引擎或摩擦声），而以人为活动为主的场景频谱纹理更具随机性。metro_station 与 metro 虽然名字相似，但前者是地铁站（已知类）、后者是地铁内部（未知类），两者频谱特征差异较大，但都与 tram 有一定相似性——这增加了跨边界混淆的风险。

### 2.4 特征空间可视化分析（06_feature_space_tsne_pca.png）

**图表核心发现：**

该图表使用 PCA 和 t-SNE 两种降维方法，将基于 MFCC 特征的音频数据投影到二维空间进行可视化。图中圆形（○）代表已知类，方块（□）代表未知类。

**PCA 可视化分析：**

在 PCA 图中，数据形成了巨大的、相互交织的中心簇。除了极少数离群点外，大部分类别在 PC1 和 PC2 构成的二维平面上完全重叠。PC1 解释了 81.9% 的方差，说明数据的主要变异集中在一个维度上，但这个维度并不足以区分不同类别。线性投影方法完全无法有效分离这些音频类别。

**t-SNE 可视化分析：**

相比 PCA，t-SNE 展现了更多的局部结构，呈现出一些细小的“岛屿”或簇状分布。然而，这些簇的纯度很低。虽然某些类别（如 park 或 street_traffic）表现出一定的局部聚集趋势，但绝大多数类别仍然呈弥散状分布，分离程度较差。

**已知类与未知类的边界清晰度：**

在两个图中，代表未知类的方块都深度嵌入并混合在代表已知类的圆形之中。不存在明显的决策边界可以区分“已知”与“未知”。这意味着仅凭 MFCC 特征的低维投影，模型很难识别出一个样本是属于已训练的已知类别，还是属于未见过的未知类别——这是开放集识别任务面临的核心挑战。

**类别混淆模式分析：**

交通相关类别（tram、bus、metro）与其已知类近邻（如 metro_station、street_traffic）严重重叠，这增加了将未知交通场景误分类为已知交通场景的风险。airport、shopping_mall、public_square 和 street_pedestrian 在两个图中几乎完全重叠在一起，这些公共场所类别的区分难度极大。park（青色方块）在 t-SNE 图中形成了相对独立的区域，这使得 park 相比其他未知类更容易被检测为“异常”。

**整体可分性评估：**

基于原始 MFCC 特征的二维可视化显示出这些音频场景在特征空间中具有极高的相似性。简单的 MFCC 特征在经过降维后，不足以提供足够的区分度来准确分类这些复杂的声学场景。可视化结果表明，闭集分类已具有挑战性，而开放集识别则更加困难，需要更强大的特征提取器（如深度神经网络）或更复杂的异常检测算法。

### 2.5 类间相似度矩阵分析（07_inter_class_similarity.png）

**图表核心发现：**

该图表通过 MFCC 特征的余弦相似度矩阵，量化展示了 10 个声学场景类别之间的特征相似程度。矩阵中数值越高（颜色越红）表示两个类别越相似，越低（颜色越蓝）表示差异越大。

**相似度分布特点：**

整个矩阵呈现出极高的整体相似度，数值范围在 0.95 到 1.00 之间。大多数单元格的值为 0.99 或 1.00，这意味着不同环境下的原始频谱统计特征表现出极强的相关性。从颜色上看，热力图几乎统一呈现深红色，直观地反映了所有类别在 MFCC 特征空间中非常接近的事实。

**最高相似度类别对分析：**

在已知类内部，airport 与 shopping_mall、street_pedestrian、public_square 之间的相似度均为 1.00，表明这些室内外公共空间场景在底层声学特征上几乎无法区分。在未知类内部，tram 与 bus 之间的相似度为 1.00，两者都是公共交通工具场景，频谱特征高度一致。在跨边界相似度方面，airport 与 tram、bus 之间的相似度也是 1.00，已知类与未知类之间不存在明显的特征边界。

**相对独特类别分析：**

只有 street_traffic（已知类）和 park（未知类）与其他类别的相似度偶尔会降至 0.95-0.97。street_traffic 的独特性来源于其明显的发动机谐波特征；park 的独特性则来源于其极低的整体能量和几乎空白的高频部分。这两个类别在特征空间中相对独立，可作为开放集检测的“锚点”参考。

**对模型训练的深刻启示：**

首先，特征判别力严重不足。仅仅依靠 MFCC 等底层声学特征无法有效区分这些场景，模型如果只学习这些特征会表现出严重的类别混淆。其次，OOD 检测难度极大。由于未知类与已知类的特征相似度极高，模型极易产生“过度自信”的错误，将未见过的场景以极高的置信度误认为某个已知场景。再次，需要更高阶的特征提取。场景的差异可能更多体现在声音随时间变化的模式上，而非平均频谱，需要利用深度神经网络学习更高层次、更抽象的语义特征。最后，建议引入对比学习策略。显式地拉近同类样本距离并推开异类样本，或在训练中加入异常检测机制，提升模型识别“我不认识这个场景”的能力。

### 2.6 数据质量评估分析（08_data_quality.png）

**图表核心发现：**

该图表通过全局和分两部分的振幅分布，直观展示了音频数据集的统计特性和潜在质量问题。左图为全局振幅分布，右图为分 10 类的振幅分布。

**振幅分布特点：**

在全局分布中，分布呈现出极高的峰值，中心位于 0.0，说明绝大多数音频样本的振幅都非常小，接近静音或背景底噪。分布在 0.0 左右表现出良好的对称性，这是正常音频信号（交流信号）的典型特征。值得注意的是，纵轴使用了对数刻度，在对数坐标下分布曲线呈线性下降，说明原始振幅分布遵循类似拉普拉斯或高斯分布的规律，即高振幅样本出现的概率随幅值增加而指数级减少。大部分数据分布在 [-1.0, 1.0] 区间内，这是音频归一化的标准范围，但坐标轴显示部分值略微超出了这一范围（达到 ±1.1 左右）。

**静音与削波问题分析：**

在 0.0 处概率密度高达 10^1（10），而其他位置迅速下降，这表明数据集中存在比例极高的静音或极低能量片段。在 ±1.0 处可以看到明显的小突起（削波尖峰），密度在 10^-4 到 10^-3 之间。虽然削波比例不算极高，但明确证实了数据中存在信号失真问题。削波是由于录音时增益过大，导致超出硬件记录范围的信号被强行截断在最大值，这会引入高频噪声并破坏原始声学特征。

**类别间差异分析：**

street_traffic 和 metro_station 的曲线底座更宽，说明这些场景包含更多高振幅成分，整体能量较高。airport 和 public_square 的分布相对较窄，说明这些录音样本整体偏安静，动态范围较小。在削波程度方面，street_traffic 和 metro_station 曲线在 ±1.0 处的突起最为明显，表明环境嘈杂的类别更容易出现录音过载导致的削波失真。

**质量问题的处理建议：**

针对静音问题，建议使用语音活动检测（VAD）或简单的能量阈值方法，剔除长段的静音片段，提高数据密度。针对削波问题，对于轻微削波的样本可以尝试使用插值算法修复，对于严重削波的样本建议直接剔除。针对归一化问题，可以采用峰值归一化将所有样本的峰值缩放到统一水平，或采用 RMS 归一化将所有样本的平均能量调整到一致以消除响度差异。此外，应强制将所有数值限制在 [-1.0, 1.0] 范围内，消除超出范围的异常值。在训练时可以随机改变音频增益，增强模型对不同录音电平的鲁棒性。

### 2.7 已知类与未知类特征对比分析（09_known_vs_unknown.png）

**图表核心发现：**

该图表以分布对比的形式，展示了五个关键频谱特征在已知类（橙色）与未知类（蓝色）之间的差异。Cohen's d 值用于量化两组均值之间的标准化差异。

**各特征区分能力分析：**

spectral_centroid（频谱质心）表现出最强的区分能力。未知类的分布明显偏向低频区域（峰值在 500-600 左右），已知类的分布主要集中在中频区域（峰值在 1000-1100 左右）。虽然两者在 750-1000 区间有重叠，但主体分布区间分化非常明显。Cohen's d 值在所有特征中最大，这表明频谱质心是单特征中区分度最高的一个。

spectral_bandwidth（频谱带宽）存在偏移但重叠较多。未知类的带宽普遍较窄（峰值在 1000 附近），已知类带宽较宽（峰值在 1400 附近）。相比频谱质心，这两者的分布重叠区域更大，区分难度稍高。

spectral_flatness（频谱平坦度）表现出极端分布差异。未知类极度集中在趋近于 0 的极小值区域，表现出极高的峰值（呈尖刺状），说明未知类具有更强的周期性或更纯的音调特征。已知类的分布虽然也靠近 0，但其“尾巴”更长，分布更散，表明已知类包含更多类噪声或宽带信号。

zero_crossing_rate（过零率）表现出较明显的偏移。未知类的过零率非常低（集中在 0.02 附近），已知类的零交叉率分布更广且均值更高（峰值在 0.05-0.07）。这与频谱质心的表现一致：未知类通常包含更多低频成分。

rms（均方根能量）表现出形态差异。已知类高度集中在低能量区间（0.05 以下），而未知类的能量分布非常宽且均值明显高于已知类。这意味着未知类样本在音量/能量上通常比已知类更大且波动更剧烈。

**已知类与未知类的区分边界评估：**

虽然没有任何单一特征能够提供绝对的硬边界，但在多维空间中这些特征的组合可以形成更清晰的判别模式。例如，一个“低质心 + 低过零率 + 高能量”的样本极大概率属于未知类。park 作为未知类，在各个特征上的分布都较为极端——能量极低、频谱质心偏低，这使得它相比其他未知类更容易被检测为“异常”。

**对开放集检测模型设计的具体建议：**

在特征融合策略方面，应利用 spectral_centroid 和 rms 的互补性，已知类通常是“中高频、低能量”，而未知类倾向于“低频、高能量”，多特征组合判断比单一阈值更可靠。在基于距离的异常检测方面，可以使用马氏距离或极值理论来建模已知类的边界，任何远离已知类分布中心的样本都应被标记为“未知”。在生成式辅助模型方面，可以训练一个仅针对已知类的自编码器，未知类样本在重构时会产生更高的重构误差。在 softmax 阈值优化方面，针对未知类往往表现出“低置信度”的特点，可以结合特征分布设置动态的拒绝阈值。

## 三、综合总结与建议

### 3.1 数据集核心特点总结

**开放集识别面临的挑战：**

首先，已知类与未知类之间存在高度的特征重叠。类间相似度矩阵显示，几乎所有类别对之间的 MFCC 余弦相似度都在 0.95 以上，这意味着无论是闭集分类还是开放集识别，任务都具有相当大的难度。模型在训练阶段只能接触到已知类，完全无法学习“未知”的边界，这要求模型必须具备识别“陌生模式”的内在能力。

其次，MFCC 等底层声学特征表达力不足。从 t-SNE 和 PCA 可视化可以清晰看到，基于 MFCC 统计特征的数据在降维后高度重叠，简单的特征工程方法难以提供足够的区分度。需要利用深度神经网络学习更高层次的抽象表征。

再次，部分类别存在严重的类内差异。street_traffic 和 metro_station 等高能量类别内部样本变化范围很大，这增加了学习稳定表示的难度。

**数据集的有利因素：**

首先，类别分布完全均衡。所有类别在各自的数据划分中样本量完全相等，这消除了类别不平衡带来的干扰，使得性能评估更加可靠。

其次，存在一些具有区分力的特征。虽然单特征无法完美区分，但 spectral_centroid、zero_crossing_rate 和 spectral_flatness 在已知类与未知类之间表现出统计显著差异，可用于设计开放集检测模块。

再次，park 具有明显的异常特性。作为唯一的自然静谧场景，park 在频谱和能量特征上都表现出极端值，这使其相比其他未知类更容易被检测。

### 3.2 开放集识别模型训练建议

**特征学习层面：**

建议使用深度卷积神经网络（如 VGGish、YAMNet 或自定义 CNN）学习高层次的声学表征，而非依赖手工特征的简单分类器。引入对比学习方法（如 SimCLR、MoCo），显式地拉近同类样本、推开异类样本，有助于在特征空间中创造更清晰的类间边界。考虑使用注意力机制或 Transformer 结构，捕获长程时序依赖，这对于区分具有不同时间结构的场景（如 tram 的节奏性脉冲 vs metro 的持续低频）尤为重要。

**开放集检测机制层面：**

可以尝试训练一个仅针对已知类的自编码器，使用重构误差作为异常分数，未知样本通常会产生更大的重构误差。也可以基于 softmax 输出置信度或能量函数方法，低于置信度阈值的样本被标记为未知类。还可以引入基于距离的方法，使用 KNN 或基于密度的方法检测远离已知类聚类的样本。极值理论（EVT）可用于校准已知类边界的置信度分数。

**损失函数设计层面：**

可以考虑使用 OpenMax 等开放集识别专用的损失函数，对已知类的 logit 进行重新校准。引入对比损失或三元组损失，显式地最大化类间距离、最小化类内距离。对于高相似度类别对（如 airport-shopping_mall、street_traffic-bus），使用更大的间隔损失权重。

### 3.3 聚类模型训练建议

**聚类策略：**

由于训练集中未知类数量为零，聚类任务主要针对测试集的未知样本。可以采用两阶段策略：先用开放集检测将样本分为“疑似未知”和“已知”，对“疑似未知”样本进行聚类以发现潜在的子类结构。使用 DBSCAN 或 HDBSCAN 等基于密度的聚类方法，可以自动发现聚类数量而不需要预设。

**聚类评估指标：**

可以使用标准化互信息（NMI）和调整兰德指数（ARI）评估聚类质量。由于真实的未知类标签已知，可以计算聚类结果与真实标签之间的对应关系。如果 park 单独形成一个聚类，说明聚类算法能够捕获真实的类别结构。

**时序特征的重要性：**

从平均频谱图可以看到，tram 的节奏性脉冲模式、metro 的持续稳定模式都是时间维度的特征。静态帧级特征可能不足以捕获这些动态模式，建议使用考虑时序上下文的方法（如 CNN+LSTM、TimeDistributed CNN 或 Transformer）。

### 3.4 数据预处理建议

**标准化处理：**

建议将所有音频振幅严格限制在 [-1.0, 1.0] 范围内，消除异常值。可以采用全局 RMS 归一化消除不同录音电平的影响。对于需要保留能量信息的任务，可以保留原始能量分布或采用峰值归一化。

**静音过滤：**

建议剔除 RMS 低于阈值的静音片段，提高数据密度。可以使用能量阈值 VAD 方法，保留高于背景噪声 10-20 dB 的有效片段。

**数据增强建议：**

时间维度增强包括随机裁剪、时移（time shifting）、时间拉伸。频率维度增强包括噪声注入（添加高斯噪声、粉红噪声或白噪声）、混响模拟。音量增强包括随机增益调整（±6 dB 范围）。Mixup/Cutmix 增强可以提高模型对未知样本的鲁棒性。
